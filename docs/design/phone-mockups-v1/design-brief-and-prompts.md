# Visual design brief and generation prompts

## Agreed scope

English; suggested teal/navy visual direction; both light and dark modes; phones only; eight approved main pages. Deliverables are eight PNG comparison boards containing sixteen phone screen designs.

## Generation method

Built-in image generation tool (`image_gen`), not an API/CLI fallback. No application implementation was created. The home board was generated and then adjusted to realistic phone proportions. The selected home board was used as the edit/template reference for each other page to keep the visual language consistent. All final boards were visually inspected.
