# Clinic Management System — Visual Review

Eight main phone pages, each shown in **English, light mode and dark mode**. Each PNG is one side-by-side comparison: light on the left, dark on the right.

**Phase 1 only.** These are static generated images, not an interactive app. No Flutter, backend, API, or database code has been created. Patient details are fictional, contact numbers are masked, and pages illustrate separate workflow states rather than a live synchronized session.

## Design direction

- Placeholder clinic name: **Main Clinic**.
- Light theme: white and soft neutral surfaces, navy text, teal actions.
- Dark theme: navy surfaces, light text, mint actions.
- Assistant: fast search, scheduling, and a protected patient queue.
- Doctor: prominent patient identity, alerts, consultation editing, and history.

## Review notes

The queue image shows a patient already with the doctor, so the next handoff is disabled. The assistant profile illustrates restricted clinical access. The consultation image illustrates an offline draft and a file waiting for connection. Medical history includes visible amendment history.

These concepts have been visually inspected for the intended page content and theme pairing. They have not undergone usability, accessibility, clinical safety, or implementation testing. Exact spacing, text metrics, and interaction behavior remain subject to review.
